# MZ-2500 対応メモ

このリポジトリでは、MZ-2500 向けの実行環境として `sosmz2500` と `mz25iocs` を追加しています。

## `sosmz2500`

S-OS 上で動作させるための環境です。

- S-OS 用の標準入出力、ファイル、SOROBAN ライブラリを利用します。
- MZ-2500 用 MAGIC ライブラリをリンクします。
- 既存の S-OS 向け D88 作成フローと同じく、HuDisk を利用します。

## `mz25iocs`

MZ-2500 の BASIC システム / IOCS 上で動作させるための最小環境です。

- IOCS を使った `PRINT` と `INKEY` の最小ランタイムをリンクします。
- グラフィック IOCS など、機種依存の描画機能はまだ含めていません。
- `make run ENV=mz25iocs` では、外部ツール `mzd88` を使って D88 イメージを作成します。
- `mzd88` は `make setup-tools` の取得対象に含まれています。
- 作成した D88 には、メインプログラムと起動用 BASIC コード `runtime/mz2500/J8000.bas.bsd` を格納します。内容は、画面消去、マシン語領域の確保、メモリへのロード、実行を行うだけの簡単なコードです。バイナリの実行開始アドレスは &H8000 としています。開始アドレスは mz25iocs.env に記述しています。開始アドレスなどを変更する場合は、起動用 BASIC コードも合わせて修正する必要があります。その他必要な場合は修正してください。

### 入力ランタイムの挙動

`mz25iocs` の `GETL` / `GETLIN` / `LINPUT` / `INPUT` は IOCS の `SVC_GETL` を利用します。`SVC_GETL` は現在行のカラム 0 からの文字列を IOCS 内部バッファに返すため、S-OS 版との互換を考えて次のように扱っています。

- `GETL(buffer)` は、現在行のカラム 0 から読みます。
- `GETLIN(buffer, length)` は、現在行のカラム 0 から最大 `length` 文字を読みます。
- `LINPUT(buffer, length)` は、入力開始時のカーソル X 座標ぶんを読み飛ばし、プロンプト部分を除いた入力文字列を返します。
- `INPUT()` も `LINPUT` と同じくプロンプト部分を除いた文字列を数値として解釈します。

カーソル座標は IOCS ワークの `$05E2` / `$05E3` にあり、WORD として `HL` に読む場合は `L = X`, `H = Y` になります。1 バイトずつ読む場合は `$05E2` が X 座標、`$05E3` が Y 座標です。

### `LOCATE`

`mz25iocs` の `LOCATE(x, y)` は IOCS の `SVC_CMOV` を利用します。`SVC_CMOV` は `L = X`, `H = Y` としてカーソル座標を受け取るため、ランタイムでは第2引数の Y 座標を `H` に入れて呼び出しています。

## サンプル

`examples/MZ25IOCS.SL` は、`mz25iocs` の `PRINT` と `INKEY`, `INPUT`, `LINPUT` 等入出力処理を確認するための最小サンプルです。

```sh
make ENV=mz25iocs TARGET=examples/MZ25IOCS asm
make ENV=mz25iocs TARGET=examples/MZ25IOCS run
```

`run` ターゲットを使う場合は、`mzd88` にパスが通っているか、`MZD88=/path/to/mzd88` を指定してください。

`mzd88` は以下のリポジトリで管理しています。

- https://github.com/issaUt/mz2500-tools
