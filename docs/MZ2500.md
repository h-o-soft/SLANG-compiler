# MZ-2500 対応メモ

このリポジトリでは、MZ-2500 向けの実行環境として `sosmz2500` と `mz25iocs` を追加しています。

## `sosmz2500`

S-OS 上で動作させるための環境です。

- S-OS 用の標準入出力、ファイル、SOROBAN ライブラリを利用します。
- MAGIC 系ライブラリは含めていません。
- 既存の S-OS 向け D88 作成フローと同じく、HuDisk を利用します。

## `mz25iocs`

MZ-2500 の BASIC システム / IOCS 上で動作させるための最小環境です。

- IOCS を使った `PRINT` と `INKEY` の最小ランタイムをリンクします。
- グラフィック IOCS など、機種依存の描画機能はまだ含めていません。
- `make run ENV=mz25iocs` では、外部ツール `mzd88` を使って D88 イメージを作成します。
- 現時点では `mzd88` は `make setup-tools` の取得対象に含めていません。
- 作成した D88 には、メインプログラムと起動用 BASIC コード `tools/J8000.bas.bsd` を格納します。内容はマシン語領域を確保して、メモリにロード、実行するだけの簡単なコードです。バイナリの実行開始アドレスは &H8000 としています。開始アドレスは mz25iocs.env に記述していますので、変更する場合はどちらも修正する必要があります。

## サンプル

`examples/MZ25IOCS.SL` は、`mz25iocs` の `PRINT` と `INKEY` を確認するための最小サンプルです。

```sh
make ENV=mz25iocs TARGET=examples/MZ25IOCS asm
make ENV=mz25iocs TARGET=examples/MZ25IOCS run
```

`run` ターゲットを使う場合は、`mzd88` にパスが通っているか、`MZD88=/path/to/mzd88` を指定してください。

`mzd88` は以下のリポジトリで管理しています。

- https://github.com/issaUt/mz2500-tools
